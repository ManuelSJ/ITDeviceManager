# ITDeviceManager

ITDeviceManager is a Windows desktop application built with C# and .NET for managing IT devices and their update and restart status.

## Project Goal

The goal of this project is to create a tool that helps IT technicians monitor computers and identify devices that require a restart after Windows updates.

The application will also allow maintenance windows to be scheduled so device restarts can be better organized.

## Planned Features

- Register and manage IT devices
- View device status
- Identify devices with pending restarts
- Schedule restart dates and times
- Track update and restart information
- Maintain a history of completed actions

## Technologies

- C#
- .NET 10
- Windows Forms
- Git & GitHub
